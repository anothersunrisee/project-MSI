## 📋 Proses Bisnis Utama

### 1. Pendaftaran Qurban (Triple-Entry — MASALAH TERVALIDASI)
```
Pendaftar WhatsApp → Sekretaris catat di buku fisik → Sekretaris input ke PC lokal
```
> ✅ **Terverifikasi:** Keterangan Bpk. Mardiyanto langsung

### 2. Khatib Jumat
- Terjadwal **1 tahun penuh** di awal tahun
- Ada ustadz **badal** jika khatib batal

### 3. Pelaporan ke KUA
- Pelaporan PHBI (Idul Fitri & Qurban) ke KUA Gondokusuman
- Masih bersifat **insidental manual** pasca-acara
- Dasar hukum: PMA No. 34 Tahun 2016
- → [[KUA Kec. Gondokusuman/KUA - Alur Pelaporan]]

- → [[BAZNAS Kota Yogyakarta/BAZNAS - Profil]]
