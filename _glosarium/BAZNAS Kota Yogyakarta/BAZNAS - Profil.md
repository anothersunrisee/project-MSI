# 📊 BAZNAS — Badan Amil Zakat Nasional Kota Yogyakarta

> **Relevansi ke MBBH:** BAZNAS adalah penerima laporan ZIS dari MBBH dan pembina standardisasi pengelolaan zakat.

---

## 📌 Profil

| Field | Data |
|---|---|
| **Nama** | BAZNAS Kota Yogyakarta |
| **Atasan** | BAZNAS Pusat / Kemenag |
| **Sistem Pelaporan** | **SIMBA** (Sistem Informasi Manajemen BAZNAS) |
| **Peran ke MBBH** | Penerima laporan penghimpunan & penyaluran ZIS |

---

## 📋 SOP & Alur Data

### Alur Pelaporan ZIS MBBH → BAZNAS
```
MBBH menghimpun ZIS (infaq, zakat, sedekah)
→ WAJIB laporan ke BAZNAS via SIMBA
→ Status saat ini: BELUM TERSISTEM (laporan manual insidental)
→ Format SIMBA belum diimplementasikan MBBH
```

### Sistem SIMBA
- SIMBA = platform pelaporan digital BAZNAS
- Standar audit zakat nasional
- MBBH **belum mengintegrasikan** laporan ke SIMBA

---

## 🔗 Data yang Dibutuhkan BAZNAS dari MBBH

| Data | Format SIMBA | Status MBBH |
|---|---|---|
| Total penghimpunan ZIS | Nominal per jenis (zakat/infaq/sedekah) | ❌ Tidak ada laporan tertulis |
| Data mustahik penerima | NIK + kategori mustahik | ❌ Tanpa basis data resmi |
| Laporan penyaluran | Per pos penyaluran | ❌ Tidak terdokumentasi |
