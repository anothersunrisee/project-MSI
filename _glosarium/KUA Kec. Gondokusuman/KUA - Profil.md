# 🏛️ KUA — Kantor Urusan Agama Kec. Gondokusuman

> **Relevansi ke MBBH:** KUA adalah pengawas eksternal MBBH untuk urusan peribadatan, nikah, dan pelaporan PHBI.  
> KUA juga sebagai PPAIW (Pejabat Pembuat Akta Ikrar Wakaf) untuk tanah masjid.

---

## 📌 Profil

| Field | Data |
|---|---|
| **Nama** | KUA Kecamatan Gondokusuman |
| **Wilayah** | Kecamatan Gondokusuman, Kota Yogyakarta |
| **Atasan** | Kemenag Kota Yogyakarta |
| **Peran ke MBBH** | Penerima laporan PHBI; PPAIW tanah wakaf |

---

## 📋 SOP & Alur Data

### 1. Penggunaan Aula Masjid
```
MBBH catat jadwal → Sinkronisasi ke KUA (untuk agenda nikah & bimbingan pernikahan)
→ Status saat ini: MANUAL / INSIDENTAL (belum sistematis)
```

### 2. Pelaporan PHBI ke KUA (PMA No. 34 Tahun 2016)
```
MBBH menggelar Idul Fitri/Qurban
→ WAJIB laporan ke KUA Gondokusuman
→ KUA teruskan ke Kemenag Kota Yogyakarta
→ Status saat ini: INSIDENTAL MANUAL pasca-acara (belum terstandar)
```
**Dasar hukum:** PMA No. 34 Tahun 2016 tentang Organisasi dan Tata Kerja KUA

### 3. Pengelolaan Tanah Wakaf
```
Tanah wakaf MBBH → legalitas di bawah BWI (Badan Wakaf Indonesia)
→ KUA sebagai PPAIW (Pejabat Pembuat Akta Ikrar Wakaf)
```

## ⬆️ Alur Vertikal: KUA → Kemenag Kota

```
MBBH
  ↓  laporan PHBI (PMA 34/2016)
KUA Gondokusuman
  ↓  rekapitulasi wilayah
Kemenag Kota Yogyakarta
  ↓  laporan tingkat kota
Kemenag Provinsi DIY
```
