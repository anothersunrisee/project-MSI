# 📚 BADKO TPA — Badan Koordinasi TPA Kemantren

> **Relevansi:** BADKO TPA adalah penghubung antara TPA Baitul Hikmah dengan Kemenag untuk proses perizinan (IZOP) dan pelaporan.

---

## 📌 Profil

| Field | Data |
|---|---|
| **Nama** | BADKO TPA Kemantren |
| **Level** | Kemantren (setara Kecamatan) |
| **Atasan** | Kemenag Kota Yogyakarta |
| **Peran Utama** | Koordinator & penghubung TPA ↔ Kemenag |

---

## 📋 SOP & Alur Data

### Alur Perizinan IZOP TPA
```
TPA mengajukan IZOP
→ Konfirmasi ke Kemenag HARUS via japri pribadi staf (tidak ada jalur formal)
→ BADKO TPA menjadi penghubung TPA ↔ Kemenag
→ IZOP TPA Baitul Hikmah sudah terbit ✅
```
*Sumber: WhatsApp Mas Jefri, 7 Sep 2026*

### Alur Pelaporan Rutin
```
TPA Baitul Hikmah
  ↓  laporan kegiatan & data santri
BADKO TPA Kemantren
  ↓  rekapitulasi wilayah kemantren
Kemenag Kota Yogyakarta
```
